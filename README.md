# 🧮 JavaScript Calculator

A simple and interactive calculator built with core web technologies to process mathematical operations and demonstrate advanced UI handling concepts.

🔗 **[Live Demo: Click here to try the calculator](https://saif-alhaysuni.github.io/javascript-calculator/)**

## 🚀 Technologies Used
* **HTML5:** Semantic structure of the calculator.
* **CSS3:** UI design using CSS Grid with interactive hover and active states.
* **JavaScript (Vanilla):** Core logic, featuring Event Delegation and robust Error Handling (Try...Catch).

## ✨ Features
* Interactive and visually appealing user interface.
* Accurate basic mathematical operations with decimal rounding.
* Smart error handling to prevent app crashes on invalid inputs.
* Delete last entry (DEL) and All Clear (AC) functionality.
